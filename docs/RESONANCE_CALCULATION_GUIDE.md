# DUVA Resonance 计算说明

## Resonance 回答的问题

Resonance 衡量某个 Sleep Day 与此前已经显现的 Rhythm Pattern 有多接近。当前 Sleep Day 始终留在参照数据之外，避免它参与建立自己的标准。

## 计算流程

1. 读取当前 Sleep Day 的主睡眠。数据包含入睡和醒来时间、睡眠时长、整夜睡眠分期、Deep／Light／REM 比例、睡眠期间心率、静息心率、心率稳定时间，以及前 90 分钟的短暂清醒和分期转换。
2. 将时间窗口停在当前夜晚之前，重新计算当时已经达到可见条件的 Pattern。未来夜晚和当天数据不会进入参照。
3. 将当前夜晚依次与每个可见 Pattern 比较。每个 Pattern 都会获得独立契合分数，然后按得分排序。
4. 使用六个维度形成基础分数：睡眠时间 28%、睡眠时长 12%、睡眠深度 Landscape 25%、分期组成 12%、夜间心率形态 16%、前 90 分钟结构 7%。
5. 某项数据缺失时，该项退出本次计算，其余权重按比例重新分配。缺少心率不会自动降低睡眠结构的契合程度。
6. Pattern Confidence、Pattern 核心夜晚数量、当晚信号覆盖和当晚数据质量共同约束结果。参照较弱时，极端分数会向中间收缩。
7. 选取得分最高的 Pattern，并检查它与第二名的差距。页面同时显示被选 Pattern、第二名和各维度分数，用户可以看到结论来源。

## 六个契合维度

- 睡眠时间：比较入睡与醒来时间是否落在 Pattern 的稳定时间范围附近。
- 睡眠时长：比较主睡眠时长与 Pattern 的代表范围。
- 睡眠深度 Landscape：将整夜分期转成相对时间上的深度轨迹，比较整条轨迹的形状。
- 分期组成：比较 Deep、Light、REM 的整体比例。
- 夜间心率形态：比较睡眠心率中位值、夜间低点、静息心率与入睡后的心率稳定时间。
- 前 90 分钟结构：比较入睡初段的短暂清醒与睡眠分期转换频率。

## 状态解释

- 82–100：`Close match`。当前夜晚与一个 Pattern 高度契合。
- 70–81：`Familiar shape`。主要结构清楚地接近一个 Pattern。
- 58–69：`Some shared terrain`。存在可识别的共同形态，差异仍然明显。
- 最高分低于 58：`This night was different`。页面显示最接近的 Pattern 作为比较对象，不把当前夜晚归入它。
- 前两名均达到 58，且分差小于 6：`Between two patterns`。页面同时显示两个 Pattern 及其分数。
- 当前夜晚之前没有可见 Pattern：显示 `We need more nights of sleep data to form your first Pattern.`，不生成 Resonance 分数。

## Sleep Landscape

- 水平轴上方的薄荷色形态代表当前夜晚的主睡眠。
- 水平轴下方的暗薄荷色形态是当前主睡眠的镜像。
- 紫色区域代表参照 Pattern 在每个时间点的睡眠深度概率分布。15%–85% 外缘控制范围，局部概率越高，颜色越深。
- 倒影轮廓落进紫色 Pattern 概率带时，对应线段显示为金色。金色线段用于解释匹配位置，不单独决定 Resonance 分数。

## Context 的边界

运动、饮食、酒精、推测工作日和休息日、周期性规律属于 Pattern 形成后的 Context 分析。这些数据可以解释 Pattern 在什么条件下更常出现，不进入当前夜晚的 Resonance 计算。
